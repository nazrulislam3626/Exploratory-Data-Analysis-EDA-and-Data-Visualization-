# Exploratory-Data-Analysis-EDA-and-Data-Visualization-

# Insights & Interpretation         
This project focused on building a credit risk prediction system using the German Credit Risk dataset. The main objective was to classify loan applicants into Good Risk or Bad Risk categories based on customer-related and loan-related information such as age, sex, job, housing status, saving account, checking account, credit amount, loan duration, purpose, and risk status. The dataset contained 1,000 records and initially included missing values in the “Saving accounts” and “Checking account” columns, which were handled through mode-based imputation. Unnecessary columns were removed, duplicate records were checked, and categorical variables were converted into numerical format for machine learning model training.

The project followed a complete machine learning workflow. First, the dataset was loaded and explored using basic statistical analysis, missing value checks, and feature descriptions. Then, data cleaning and feature engineering were performed, including label encoding, duplicate checking, and feature selection. Exploratory Data Analysis was also conducted using histograms, boxplots, bar charts, pie charts, scatter plots, violin plots, pair plots, and a correlation heatmap. The visual analysis showed that credit amount was right-skewed, most applicants had their own housing, and the most common credit purposes were car, radio/TV, and furniture/equipment. The correlation analysis indicated that Duration and Credit amount had stronger negative relationships with good credit risk, meaning longer loan duration and higher loan amounts were more associated with bad risk cases.
A major issue in the dataset was class imbalance. The original target distribution showed 700 good risk and 300 bad risk cases. To improve model learning, upsampling was applied to balance both classes to 700 good and 700 bad samples. After balancing, several machine learning models were trained and compared, including Logistic Regression, Support Vector Machine, Linear SVC, K-Nearest Neighbors, Naive Bayes, Perceptron, Stochastic Gradient Descent, Decision Tree, Random Forest, XGBoost, Gradient Boosting, and AdaBoost. Model performance was evaluated using accuracy, precision, recall, F1-score, confusion matrix, ROC-AUC curve, and cross-validation.

The overall outcome shows that tree-based ensemble models performed better than traditional linear models. XGBoost and Random Forest were the strongest performers because they handled non-linear relationships better than Logistic Regression, SVM, and Naive Bayes. The final proposed model was XGBClassifier, selected because it gave strong predictive performance, faster execution compared with Random Forest, and better generalization than single Decision Tree models. The final XGBClassifier test accuracy reported in the notebook was 84.29%, and 10-fold cross-validation produced a mean accuracy of 84.36% with a standard deviation of 0.0173, showing stable performance across folds.

Overall, the project successfully demonstrates how machine learning can support credit risk assessment by predicting whether an applicant is likely to be a good or bad credit risk. The model can help financial institutions make faster, more consistent, and data-driven credit decisions. However, the project can be further improved by applying leakage-free balancing after train-test split, using one-hot encoding instead of only label encoding for nominal variables, adding hyperparameter tuning, and including explainability methods such as feature importance or SHAP analysis. Despite these limitations, the project provides a strong practical foundation for credit risk classification using machine learning.
